Houdini 用語辞典

Houdiniは略語と英語の専門用語が多く、意味が分からないまま読み進めると手が止まる。 前提知識なしで読めるようにまとめた。カタカナ読みを併記しているのは、そもそも何と読むのか 分からない語が多いため。

ネットワークと文脈

Houdiniは「どの階層で作業しているか」で使えるノードが変わる。その階層の名前が SOP や DOP といった略語になっている。

ノード / Nodeノード
ひとつの処理を表す箱。入力を受け取り、加工して出力する。Houdiniではこの箱をつないで結果を作るため、作業そのものが「箱をつなぐこと」になる。
ネットワーク / Networkネットワーク
ノードをつないだ全体のこと。上から下へ流れる図として表示され、これを編集する画面をネットワークエディタと呼ぶ。
SOPソップ · Surface Operator
ジオメトリ（形）を扱うノードの階層。box、mountain、subdivide など、モデリングで使うノードはほぼSOP。Houdiniで最初に慣れるべき場所。関連: ジオメトリ
POPポップ · Particle Operator
パーティクル（粒子）を扱うノードの系統。火花、雨、群衆のように「たくさんの小さなものが動く」表現に使う。シミュレーション用のネットワークの中で組む。関連: DOP, シミュレーション
DOPドップ · Dynamics Operator
シミュレーション（物理計算）を扱う階層。破壊、布、煙、液体などはここで計算する。時間をフレームごとに進めながら結果を積み上げていくのが特徴。関連: ソルバ, シミュレーション
VOPボップ · VEX Operator
VEXの処理をノードをつないで組み立てる階層。コードを書く代わりに図で書くVEX、という位置づけ。関連: VEX
ROPロップ · Render Operator
出力を担当するノードの階層。画像のレンダリング、ファイル書き出しなど「最終的に何かを外に出す」処理はここ。関連: Karma, OpenGL ROP
OBJオブジェ · Object
シーンに置く「物体」の階層。カメラ、ライト、ジオメトリの入れ物（geoノード）などが並ぶ。SOPはこのgeoノードの中に入っている。
LOPロップ · Lighting Operator
USDベースでシーンを組む階層。Solarisとも呼ばれる。ライティングやレンダリングの設定を扱う新しい仕組み。
プロシージャルモデリング / Procedural modelingプロシージャルモデリング
形を手で作り込むのではなく、手順（ノードのつながり）として組み立てるやり方。あとから数値を変えるだけで作り直せるのが利点で、Houdini の中心的な考え方。関連: ノード / ネットワーク
エフェクト / FXエフェクト
破壊・煙・炎・水・パーティクルなど、時間とともに変化する表現の総称。形を作るモデリングに対して、動きを計算させる側を指す。関連: シミュレーション
チャンネル / Channelチャンネル
ノードの入出力を役割ごとに分けた筋道。FLIP では「液体の粒」「容器」「衝突」の3つのチャンネルが並んで流れており、対応する入口と出口をつなぐ必要がある。関連: FLIP
コンテキスト / Contextコンテキスト
ノードを置ける場所の種類。形を扱う SOP、物理を扱う DOP、光を扱う VOP のように分かれていて、置ける箱も違う。画面の左上に、いまどこにいるかが出る。
/objオブジェ
シーンに物を置く一番外側の階層。カメラ・ライト・形の入れ物（geo）が並ぶ。SOP はこの geo の中に入っている。関連: OBJ, SOP
/outアウト
書き出しを並べる階層。レンダリング、ファイル保存はここに置く。ROP と呼ばれるノードが入る。関連: ROP
/stageステージ
USD でシーンを組む階層。Solaris と呼ばれる仕組みがここで動く。関連: LOP, USD
/matマット
材質を組む階層。principledshader などがここに入る。関連: VOP, マテリアル
サブネット / Subnetサブネット
複数のノードをひとつの箱にまとめたもの。中に入って編集でき、外からはひとつのノードとして見える。散らかったネットワークを整理するのに使う。
表示フラグ / Display Flagひょうじふらぐ
どのノードの結果を画面に出すかを決める印。青い丸で示される。DOP では、この印が付いた箱が計算される対象になるので、付け忘れると何も起きない。関連: バイパスフラグ
バイパスフラグ / Bypassばいぱす
そのノードを一時的に素通りさせる印。入ってきたものがそのまま出る。効果があるかを見比べるときに使う。
ロックフラグ / Lockろっく
そのときの結果をノードの中に固めて、上流の変化を受け付けなくする印。重い計算を止めておきたいときに使う。
テンプレートフラグ / Templateてんぷれーと
編集の対象ではないが、参考として画面に薄く出しておく印。元の形を見ながら別のノードを触りたいときに使う。関連: 表示フラグ
クック / Cookクック
ノードが実際に計算すること。上流が変わると、下流は必要になったときに改めてクックする。変わっていなければ前の結果を使い回す。
依存関係 / Dependencyいぞんかんけい
どのノードがどのノードの結果を使っているか。つまみを参照で書くと、線がつながっていなくても依存が生まれる。
マルチパラメータ / Multiparmマルチパラメータ
同じ組のつまみを何組も増やせる仕組み。内部名は name1、name2 のように末尾の数で区別する。attribcreate や rbdconfigure がこの形。
スペアパラメータ / Spare Parameterスペアパラメータ
ノードに自分で足したつまみ。HDA を作るときや、深い所のつまみを表に出したいときに使う。
式 / Expressionしき
つまみに直接書く計算。$F でフレーム番号、ch("..") で他のつまみの値を引ける。固定値の代わりに、計算で決めたいときに使う。関連: HScript, $F
HScriptエイチスクリプト
Houdini の古いほうのスクリプト言語。つまみの式や、一部のコマンドで今も使われる。本格的な処理は Python か VEX で書く。
相対パス / Relative Pathそうたいぱす
いまいる場所から見たノードの場所。../ で1つ上に上がる。絶対パスで書くより、まとめて複製したときに壊れにくい。

ジオメトリの構成要素

Houdiniは形を「ポイント」「バーテックス」「プリミティブ」に分けて扱う。ここの区別が分かるかどうかで理解度が大きく変わる。

ジオメトリ / Geometryジオメトリ
形のデータそのもの。ポイントやプリミティブの集まりを指す。ノードからノードへ流れていくのはこのジオメトリ。
ポイント / Pointポイント
空間上の位置を持つ点。位置は必ず P という属性として持っている。形の頂点にあたるが、Houdiniでは「位置を持つだけの存在」として独立している。関連: バーテックス, P
バーテックス / Vertexバーテックス
プリミティブ（面）の角。どのポイントを使うかを指し示すだけの存在。2つの面が同じ角を共有している場合、ポイントは1つだがバーテックスは2つある。UVや面ごとの法線はこちらに乗る。初心者が最も混乱する区別。関連: ポイント, プリミティブ
プリミティブ / Primitiveプリミティブ
面や線、ボリュームなど「形の単位」。ポリゴン1枚がプリミティブ1つ。立方体なら6面あるのでプリミティブは6つ。prim と略される。関連: ポリゴン, バーテックス
ポリゴン / Polygonポリゴン
3つ以上のバーテックスで囲まれた面。プリミティブの一種で、モデリングで最もよく使う種類。
アトリビュート / Attributeアトリビュート
ジオメトリに付けられる名前付きのデータ。位置、色、速度、大きさなど何でも持たせられる。Houdiniの柔軟さの正体はこれで、「必要な情報を自分で作って後段のノードに渡す」のが基本的な考え方。属性とも書く。関連: P, N, Cd, ディテールアトリビュート
Pピー
ポイントの位置を表すアトリビュート。x, y, z の3つの数値。すべてのポイントが必ず持っている。
Nエヌ · Normal
法線。面や点が向いている方向を表すベクトル。ライティングの計算や、押し出す方向の基準に使われる。関連: 法線
Cdシーディー · Color diffuse
色を表すアトリビュート。RGBの3つの数値。color SOP を通すとこれが追加される。
pscaleピースケール
ポイントごとの大きさ。copy to points で形を複製するときに、このアトリビュートで1つずつサイズを変えられる。関連: copy to points
@ptnumアットピーティーナム · point number
ポイントの通し番号（0から始まる）。VEXの中で「何番目の点か」を知るために使う。@ が付く書き方はVEXでのアトリビュート参照。関連: VEX
ディテールアトリビュート / Detail attributeディテールアトリビュート
ジオメトリ全体に1つだけ持たせる値。ポイントごとではなく「この形全体の設定」を渡したいときに使う。グローバルアトリビュートとも呼ばれる。関連: アトリビュート
トポロジ / Topologyトポロジ
ポイントがどうつながって面を作っているか、というつながり方の構造。位置を動かしてもトポロジは変わらないが、分割したり穴を開けると変わる。
法線 / Normalほうせん
面が向いている向きを示す矢印。裏表の判定やライティングに使われる。これが裏返っていると面が真っ黒に見えたり消えたりする。関連: N
UVユーブイ
テクスチャ（画像）を形に貼るための座標。3Dの形を平面に展開した位置を、バーテックスごとに持たせる。関連: バーテックス
バウンディングボックス / Bounding boxバウンディングボックス
ジオメトリ全体がちょうど収まる直方体。大きさや位置の目安として使われ、これを基準に色を付けたり配置したりできる。bbox と略される。
グループ / Groupグループ
ポイントやプリミティブに名前を付けた選択範囲。「この部分だけに処理をかけたい」というときに作る。
ボリューム / Volumeボリューム
空間を格子状に区切って、各マスに値を持たせたデータ。煙や炎のように「面では表せない、中身のあるもの」を扱うのに使う。VDBはその代表的な形式。関連: Pyro
ボクセル / Voxelボクセル
空間を細かい立方体のマス目に区切ったときの、1マスのこと。画像のピクセルを立体にしたもの。ボリュームはボクセルの集まりでできていて、マス目が細かいほど煙の形も細かくなる代わりに計算が重くなる。関連: ボリューム
パックプリミティブ / Packed primitiveパックプリミティブ
中身のジオメトリを1つのプリミティブとしてまとめて持つ仕組み。破片のように同じ形を大量に扱うときに軽くなる。中身を取り出すには unpack を使う。関連: プリミティブ
メッシュ / Meshメッシュ
面がつながってできた形の全体。ポリゴンを網の目のように並べたもの。分割の細かさを「メッシュが細かい／粗い」と言う。関連: ポリゴン / トポロジ
テンプレート / Templateテンプレート
複製のもとになる形。copy to points では、この形が点の数だけコピーされる。向きは、テンプレートの Z 軸が点の N に合わせられる。関連: copy to points / N
HeightField / ハイトフィールドハイトフィールド
地形を「高さの数の並び」として持つ仕組み。面も点も持たず、2次元のボリューム（height）1枚で地形を表す。浸食のような計算ができるのが利点で、レンダする直前にメッシュへ直す（実験034）。
レイヤー / Layerレイヤー
HeightField が重ねて持つボリュームの1枚。最初は height と mask の2枚だが、浸食をかけるとがれき・堆積・流れなどが足されて7枚になる。「どこが削れたか」を色や散布に使える（実験034）。
MPMエムピーエム · Material Point Method
Houdini 21 から入ったソルバ。砂・雪・泥・パンのような「固体と流体の中間」を扱う。物を粒の集まりとして持ち、計算のときだけ格子に移して解く。mpm で始まる SOP が8種、DOP が2種ある（実験061）。関連: ソルバ / シミュレーション
APEXエイペックス
Houdini 20 から入った、リグ（骨組み）を組み立てる仕組み。ノードのネットワークそのものをデータとして持ち歩けるのが特徴で、シーンの中ではなくジオメトリの中に入って流れる。使える部品は 2,220種あり、そのうち 715種は SOP とジオメトリを触るためのもの（実験050）。関連: KineFX / リグ
KineFXキネエフエックス
Houdini で骨組み（スケルトン）とアニメーションを扱う仕組み。骨を「点と線のジオメトリ」として持つので、普通の SOP でそのまま加工できる。kinefx:: で始まる SOP が 133種ある（実験050）。関連: APEX / リグ
リグ / Rigリグ
キャラクターを動かすための骨組みと操作系。手で1点ずつ動かす代わりに、少数の「つまみ」で全身を制御できるようにする仕組み。関連: APEX / KineFX
可変長の入力 / VariadicArgカヘンチョウノニュウリョク
つなぐ数を決めずに、いくつでも受け取れる入力口。APEX の Add はこの形で、枝（サブポート）を生やした数だけ足せる。値を直接入れても無視され、エラーも出ないので気づきにくい（実験050）。関連: APEX
グルーム / Groomグルーム
毛や髪を作って整えること。Houdini では2段構えで、ガイド（案内役、数百本）で形を決め、そこから毛（数万本）に増やす。guide で始まるノードだけで26種ある（実験042・043）。関連: ガイド / clumpid
ガイド / Guideガイド
毛の形を決める案内役の線。実際にレンダされる数万本の毛は、数百本のガイドから増やして作る。ガイド1本は polyline で、どの面から生えたかを示す skinprim をプリミティブに持つ（実験043）。関連: グルーム / skinprim
skinprimスキンプリム
毛やガイドが「土台のどの面から生えたか」を示す番号。グルームのノードはこれが無いと動かない。fur の出力には付かないので、次の工程に渡すには自分でガイドを組む必要がある（実験043）。関連: ガイド / rest
widthウィズ
カーブ（毛や線）の太さを表すアトリビュート。レンダラはこれを見て毛の太さを決める。実測したところ半径ではなく直径だった（実験045）。世界の大きさに対する値なので、小さい土台に既定の 0.001 を使うと画の上で 0.1ピクセルにしかならない。関連: グルーム / アルファ
clumpidクランプID
毛がどの束に属するかを示す番号。hairclump が付ける。種類の数を数えれば束の数が分かり、束ごとに色を変えるといった加工にも使える（実験043）。関連: グルーム
restレスト
点の「元の位置」を覚えておくアトリビュート。形が動いても模様や毛の付き方がついてこないようにするために使う。グルームの土台には必須で、無いと hairgen が止まる（実験043）。VEX の addpoint で作った点は rest が (0,0,0) のまま入り、エラーも出ないまま「原点にあるもの」として扱われる（実験044）。関連: skinprim
ポイント番号 / Point Numberポイントばんごう
点に振られた 0 から始まる通し番号。VEX では @ptnum で読める。処理の順番や、どの点とどの点を結ぶかの手がかりになる。関連: @ptnum
プリミティブ番号 / Primitive Numberプリミティブばんごう
面に振られた 0 から始まる通し番号。面を1つずつ処理するときに使う。
ポリソープ / Polygon Soupポリソープ
たくさんの面を1つのまとまりとして持つ形。面ごとの番号が無くなるぶん軽い。面を1つずつ触りたいときは、ふつうの多角形に戻す。
パックプリミティブ / Packed Primitiveパックプリミティブ
形の中身を1つの点として抱えたもの。画面に出す負担が軽くなる。中身を編集するには unpack で開く。関連: pack, インスタンス
インスタンス / Instanceインスタンス
同じ形を、実体を増やさずに何度も置くこと。位置と向きだけを持つので、数を増やしても記憶を食いにくい。
法線の向き / Normal Directionほうせんのむき
面がどちら側を表としているか。裏返っていると、影が黒く出たり、押し出しが内側に向いたりする。関連: 法線, 裏返り
頂点法線 / Vertex Normalちょうてんほうせん
同じ点でも面ごとに違う法線を持たせたもの。これがあると、角を角のまま見せられる。点に1つだけ持たせると、角が丸く見える。関連: 法線, カスプ角
カスプ角 / Cusp Angleカスプかく
これより急な折れ目は角として扱う、という境目の角度。normal ノードで決める。小さくすると面ごとの陰影がはっきりする。
UDIMユーディム
UV の平面を格子状に区切り、区画ごとに別の画像を使うやり方。1枚では足りない解像度を稼げる。関連: UV
エッジ / Edgeエッジ
2つの点を結ぶ辺。面取りや分割は辺を選んで行う。点や面とは別の単位としてグループを作れる。
境界 / Boundaryきょうかい
片側にしか面が無い辺。穴の縁がこれになる。polyfill で塞ぐ、polypath で線にまとめる、といった処理の対象。
多様体 / Manifoldたようたい
1つの辺に面が2枚までしか付いていない、素直な形。3枚以上付いていると、計算が破綻することがある。polydoctor で直せる。
裏返り / Flippedうらがえり
法線が逆を向いている面。周りと陰影が合わず、黒く抜けたように見える。reverse や polydoctor で直す。関連: 法線の向き
SDF / 符号付き距離エスディーエフ · Signed Distance Field
各升目に「表面までの距離」を入れた持ち方。内側は負、外側は正。太らせる・縮める・なめらかにするといった操作がしやすい。関連: VDB, ボクセル
フォグボリューム / Fog Volumeフォグボリューム
各升目に「どれくらい詰まっているか」を入れた持ち方。煙や霧のように、境目のはっきりしないものを表す。関連: ボリューム
バウンディングボックス / Bounding Boxバウンディングボックス
形がすっぽり入る一番小さい直方体。大きさを測る、当たり判定を粗くする、位置を揃えるといった用途に使う。
重心 / Centroidじゅうしん
点の位置を平均した場所。回転の中心や、位置合わせの基準に使う。バウンディングボックスの中心とは一致しないことがある。
曲率 / Curvatureきょくりつ
その場所がどれくらい曲がっているか。measure で測れる。角を選ぶ、曲がった所だけ処理する、といった使い方をする。
密度 / Densityみつど
どれくらい詰まっているか。ばらまく点の濃さ、煙の濃さ、物の重さのどれを指すかは文脈で変わる。
点群 / Point Cloudてんぐん
面を持たない点だけの集まり。粒の計算や、ばらまいた位置の記録に使う。
巻き方向 / Winding Orderまきほうこう
面の頂点を、どちら回りに並べているか。この向きで面の表と裏が決まる。reverse で逆にすると法線が反対を向く。関連: 法線, 裏返り
縮退 / Degenerateしゅくたい
面積が0になった面や、長さが0の辺のように、つぶれてしまった要素。計算を狂わせることがあるので、clean などで消す。
非多様体 / Non-manifoldひたようたい
1本の辺を3枚以上の面が共有しているなど、ふつうの「表面」として扱えないつながり方。ブーリアンや UV 展開がうまくいかない原因になる。関連: 多様体
連結成分 / Connected Componentれんけつせいぶん
辺や点でつながっている、ひとかたまり。バラバラの破片は、それぞれが1つの連結成分。connectivity で番号を振れる。
ピース / Pieceピース
ひとまとまりとして扱う部品。多くは name 属性で見分ける。RBD の破片や、パックする単位になる。関連: name, パックプリミティブ
縫い目 / Seamぬいめ
UV を開くときに切り開く辺。どこで切るかで、開いた形のゆがみと、テクスチャのつなぎ目の位置が決まる。関連: UV, UV アイランド
UV アイランド / UV Islandユーブイアイランド
UV の上で、ひとつながりになっている面のかたまり。縫い目で切られた単位ごとに島ができる。
テクセル密度 / Texel Densityテクセルみつど
形の単位長さあたりに、テクスチャの画素がいくつ乗るか。部品ごとにそろっていないと、模様の細かさがばらつく。
凸包 / Convex Hullとつほう
点の集まりを、外から包むいちばん小さなへこみの無い形。当たり判定を軽くするときの代わりの形に使う。
等値面 / Isosurfaceとうちめん
場の値がちょうど決まった値になる所をつないだ面。SDF なら値0の面が形の表面になる。関連: SDF, ボリューム
レベルセット / Level Setレベルセット
形を「表面からの距離の場」で表すやり方。SDF とほぼ同じ意味で使われる。和や差が足し算・引き算のように扱える。関連: SDF
ドロネー三角形分割 / Delaunay Triangulationドロネーさんかくけいぶんかつ
点を三角形でつなぐとき、どの三角形の外接円にも他の点が入らないようにする分け方。細長い三角形ができにくい。triangulate2d が使う。
拘束辺 / Constrained Edgeこうそくへん
三角形分割のときに、必ず辺として残す線。縁や穴の形を崩さずに内側を埋めるのに使う。
NURBSナーブス
制御点と重みで、なめらかな曲線や曲面を表すやり方。円や球を正確に表せる。Houdini では多角形に変換して使うことが多い。
次数 / Orderじすう
NURBS やベジエの曲線を決める多項式の高さ。Houdini の Order は次数＋1 で、4 なら3次の曲線。
四角形メッシュ / Quad Meshしかくけいメッシュ
面がすべて四角形の網。曲げや細分化（subdivide）がきれいに効くので、キャラクターや有機的な形のモデリングで好まれる。関連: 三角形メッシュ
三角形メッシュ / Triangle Meshさんかくけいメッシュ
面がすべて三角形の網。どんな形でも必ず平らな面で張れるので、ゲームエンジンやシミュレーションの受け渡しで使われる。
N-gon / 多角形の面エヌゴン
5角形以上の面。そのままだと細分化や書き出しで思わぬ割れ方をすることがある。divide で三角形や四角形に割ってから渡す。
エッジループ / Edge Loopエッジループ
四角形の網で、向かい合う辺をたどってぐるりとつながる辺の列。輪切りの線を足したり、形の流れを整えたりする単位。
極 / Poleきょく
4本以外の数の辺が集まる点。球の北極のように、網の流れが乱れる所になる。
リトポロジー / Retopologyリトポロジー
形は保ったまま、網を作り直すこと。スキャンやスカルプトの細かすぎる網を、扱いやすい四角形の網に張り直す。
回転体 / Surface of Revolutionかいてんたい
線を軸のまわりに回してできる形。壺・コップ・車輪など。revolve で作る。
円錐台 / Frustumえんすいだい
円錐の先を平らに切り落とした形。側面積は π(r1 + r2)·（斜めの高さ）。
展開可能な面 / Developable Surfaceてんかいかのうなめん
伸び縮みさせずに平らに開ける面。円筒・円錐・平面など。UV をゆがみ0で開けるのはこの形だけ。
ガウス曲率 / Gaussian Curvatureガウスきょくりつ
面の曲がり方を表す数の1つ。0 でない所（球など）は、どう開いても平らにするとゆがむ。円筒は曲がっていてもガウス曲率は0。関連: 曲率, 展開可能な面
符号付き体積 / Signed Volumeふごうつきたいせき
面の向きを考えに入れて足した体積。面が外を向いていればプラス、裏返しならマイナスになる。measure の体積がマイナスなら、形が裏返っている合図。関連: 巻き方向, 法線
厚み / Thicknessあつみ
面から反対側の面までの距離。薄すぎる所は、3Dプリントやシミュレーションで壊れやすい。measurethickness で点ごとに測れる。
超二次曲面 / Superquadricちょうにじきょくめん
指数を変えると、球から角の丸い箱、星形まで連続して変わる形の仲間。superquad で作る。
測地球 / Geodesic Sphereそくちきゅう
正二十面体の三角形を細かく分けて、点を球面に押し出した球。sphere の Polygon がこれで、点は 10f²+2、面は 20f²（f = Frequency）。三角形の大きさがそろう（実験151）。
フィレット / Filletフィレット
角を丸くつなぐこと。polybevel の Round で、Offset が丸みの半径になる（実験152）。
面取り（平ら）/ Chamferめんとり
角を平らな面で落とすこと。1×1×1 の箱を幅 d で面取りすると体積は 1 − 6d² + (16/3)d³（実験152）。
オイラー標数 / Euler Characteristicオイラーひょうすう
点の数 − 辺の数 + 面の数（V − E + F）。穴のない閉じた形は 2、板は 1、トーラスや筒は 0。形のつながり方を数だけで見分けられる（実験153）。
マイター / Miterマイター
管や線が折れる所で、2本をちょうど半分の角度で切ってつなぐこと。polywire の折れ目の輪は、この面に乗って r/cos(θ/2) に広がる（実験156）。

よく使う処理

SOPで頻繁に登場する処理。名前が動作をそのまま表しているものが多い。

subdivideサブディバイド
面を細かく分割するノード。分割と同時に形を滑らかにするため、立方体にかけると回数を増やすほど球に近づく。この滑らかにする方式が Catmull-Clark。関連: Catmull-Clark
Catmull-Clarkカトマル・クラーク
面を分割しながら滑らかな曲面に近づけていく計算方式。角が丸まるのが特徴で、「分割したのに形が変わった」と感じる原因はこれ。関連: subdivide
mountainマウンテン
ポイントを法線方向にノイズで押し出して、地形のような凹凸を作るノード。既存のポイントを動かすだけでポイントは増えないため、細かい凹凸を出したいなら先に分割数を上げておく必要がある。関連: ノイズ, subdivide
ノイズ / Noiseノイズ
でたらめに見えて滑らかにつながっている数値のパターン。自然物のばらつきを作るのに使われ、地形、煙、揺れなどほぼすべての「自然に見せたいもの」の元になる。
scatterスキャッター
面の上にポイントをばらまくノード。ばらまいた点にあとから草や岩を複製する、という流れがプロシージャルの定番。関連: copy to points
copy to pointsコピー・トゥ・ポインツ
ポイントの位置1つずつに、別のジオメトリを複製して配置するノード。「100個の岩を並べる」ような作業を1ノードで済ませられる、プロシージャルの中核。関連: scatter, pscale
mergeマージ
複数のジオメトリを1つにまとめるノード。別々に作った形を合流させる合流点として使う。
for-each / フォーイーチフォーイーチ
同じ処理をパーツごとに繰り返す仕組み。Block Begin と Block End という2つのノードで範囲を挟んで作る。「破片1つずつに別々の動きを付ける」など、まとめて処理できないときに使う。関連: イテレーション
イテレーション / Iterationイテレーション
繰り返し処理の1回分。10個のパーツを順に処理するなら、イテレーションは10回ある。「今が何回目か」を数値として取り出して、回ごとに違う結果にすることができる。関連: for-each
wrangleラングル
VEXのコードを直接書き込めるノード。attribute wrangle が代表。ノードを並べるより、数行書いた方が早くて分かりやすい場面で使う。関連: VEX
VEXベックス
Houdini専用のプログラミング言語。ポイント1つ1つに対して同じ計算を一斉に走らせるため非常に速い。`@P.y += 1;` のように短く書ける。関連: wrangle, VOP
polyextrudeポリエクストルード
面を押し出して厚みや突起を作るノード。建物の階や、壁からの出っ張りなどを作るのに使う。
booleanブーリアン
2つの形を足す・引く・重なりを取る、という演算をするノード。四角から円柱を引いて穴を開ける、といった使い方。
voronoi fractureボロノイ・フラクチャー
ジオメトリを細胞のような塊に分割するノード。破壊エフェクトで、壊れる前にあらかじめ破片を作っておくために使う。関連: RBD
浸食 / Erosionしんしょく
水や重力で地形が削れ、削れた土が低いところへ積もること。実験034で測ったところ、4回かけると勾配が32.7%下がり、最高は下がって最低は上がった（山が削れて谷が埋まる）。
ブーリアン / Booleanブーリアン
2つの形を重ねて、足す・引く・重なりだけ残すのどれかを行う処理。切り抜きや穴あけの基本。関連: boolean
フラクチャ / Fractureフラクチャ
ひとつの形を破片に割ること。割ったあと、破片ごとに名前が付き、つなぎ目の情報も一緒に作られる。関連: rbdmaterialfracture, 拘束
デシメート / Decimateデシメート
面の数を減らして軽くすること。Houdini では polyreduce が担う。形をなるべく保つように間引く。関連: polyreduce
転写 / Transferてんしゃ
別の形から値やグループを写すこと。点の番号ではなく距離で相手を探すので、点の数が違っても移せる。関連: attribtransfer
投影 / Projectとうえい
ある方向から形を押し当てて、相手の上に写すこと。UV を作る、地形に跡をつける、といった場面で出てくる。
レイキャスト / Ray Castレイキャスト
点から線を飛ばして、最初に当たった面を調べること。地面に物を置く、当たり判定を取る、といった処理の下地になる。関連: ray
フォーリーチ / For-Eachフォーリーチ
かたまりや番号ごとに、同じ処理を繰り返す仕組み。block_begin と block_end で挟んだ範囲が繰り返される。関連: block_begin / block_end
リサンプル / Resampleリサンプル
線の上の点を、決めた間隔で置き直すこと。並びが揃うので、あとで複製や押し出しをしたときに均一になる。関連: resample
スイープ / Sweepスイープ
線に沿って断面を引き伸ばし、管やリボンを作ること。道路・ロープ・枝などに使う。関連: sweep::2.0
面取り / Bevelめんとり
角を削って小さな面に置き換えること。光が角で拾われるようになり、硬い印象がやわらぐ。関連: polybevel
細分化 / Subdivisionさいぶんか
面を割って増やし、同時に滑らかにすること。1回ごとに面の数が大きく増える。関連: subdivide
ディスクキャッシュ / Disk Cacheディスクキャッシュ
計算した形をファイルに書いておき、次からは読むだけにすること。重いシミュレーションは、これを挟まないと毎回待つことになる。関連: filecache::2.0
フラッドフィル / Flood Fillフラッドフィル
ある所から、つながっている所へ次々に広げていくこと。グループを塊ごと選ぶときや、値を広げるときに使う。
拡散 / Diffusionかくさん
値が、まわりとの差を減らす方向へにじんでいくこと。ぼかしや、値の穴埋めの基本の考え方。
補間 / Interpolationほかん
分かっている2つ以上の値の間を、推し量って埋めること。時間の補間なら、フレームの間の形を作る。関連: 線形補間
サブフレーム / Subframeサブフレーム
1.5 フレームのような、整数でない時刻。モーションブラーやシミュレーションの細かい刻みで使う。
ポアソンディスク / Poisson Diskポアソンディスク
どの2点も決めた距離より近づかないように、点を散らす並べ方。ランダムでも片寄りやかたまりが少ない。関連: scatter
リラックス / Relaxリラックス
点どうしを押し広げたり、面の網目を整えたりして、間隔をそろえること。散らした点のかたまりを減らすのに使う。
ジッター / Jitterジッター
整って並んだものに、わざと小さな揺らぎを足すこと。格子の規則正しさを目立たなくする。
ロフト / Loftロフト
並べた断面の線の間に、面を張ること。船体や翼のような、断面が少しずつ変わる形を作る。関連: スイープ
ブリッジ / Bridgeブリッジ
離れた2つの縁の間を、面でつなぐこと。穴と穴を管で結ぶときに使う。
インスタンシング / Instancingインスタンシング
同じ形を何度も置くとき、中身を1つだけ持って、置く場所と向きだけを増やすこと。メモリが大きく減る。関連: インスタンス, パックプリミティブ
CSG / Constructive Solid Geometryシーエスジー
形どうしの和・差・積で、新しい形を組み立てるやり方。ブーリアン演算とも呼ぶ。関連: ブーリアン, 和集合
和集合 / Unionわしゅうごう
2つの形のどちらかに入っている所を全部合わせたもの。重なりは1回だけ数える。
積集合 / Intersectionせきしゅうごう
2つの形の両方に入っている所だけ。球2つなら、レンズのような形になる。
差集合 / Differenceさしゅうごう
片方の形から、もう片方と重なる所を取り除いたもの。穴あけや削り出しに使う。
オフセット / Offsetオフセット
線や面を、決まった距離だけ内側や外側にずらすこと。縁取り・厚み付け・等間隔の輪に使う。
k-means / k平均法ケーミーンズ
点を k 個の群れに分けるやり方。群れの中心を決め、近い中心に点を配り、中心を平均に動かす、をくり返す。cluster が使う。
L-Systemエルシステム
文字の書き換え規則をくり返して、植物のような枝分かれを育てるやり方。世代を重ねるほど細かくなる。
パスデフォーム / Path Deformパスデフォーム
まっすぐな形を、曲線に沿うように曲げること。ホースや文字を道に沿わせる。
ソフト選択 / Soft Selectionソフトせんたく
選んだ所だけでなく、まわりも距離に応じて少しずつ動かすこと。粘土を指でつまむような変形になる。関連: 距離減衰
継ぎ目をまとめる / Consolidate Seamつぎめをまとめる
mirror で、元と鏡像の縁の点を1つにする処理。距離がつまみの値より小さいときだけまとまる（実験145）。
Bricker（レンガ割り）ブリッカー
divide の機能。形を、決まった大きさの升目の線で切り分ける。線は形の端から並ぶ（実験149）。
凸多角形に割る / Convex Polygonsとつたかくけいにわる
へこみのある面や角の多い面を、へこみの無い小さい面に分ける。divide の既定では三角形にする。
ボロノイ分割 / Voronoiボロノイぶんかつ
種の点それぞれについて、その点に一番近い場所を1つの部屋にする分け方。voronoifracture で物を割るときの考え方。
UV のパッキング / UV Packingユーブイのパッキング
UV の島を 0〜1 の升に、重ならないように詰めて並べること。uvlayout が行う。長方形 12 枚で升の 48〜84% が埋まった（実験160）。
半シャープの折り目 / Semi-Sharp Creaseはんシャープのおりめ
細分するときに、決めた回数までは尖ったまま、そのあとはなめらかにする折り目。重み w がその回数（実験162）。
compile block（コンパイルブロック）コンパイルブロック
compile_begin と compile_end で囲んだ区間を、まとめて組み立てて速く回すしくみ。for-each を囲むと約 35% 速くなった（実験174）。
Open / Close（モルフォロジー）オープン / クローズ
形を一度痩せさせてから太らせる（Open）、または太らせてから痩せさせる（Close）処理。Open は外へ尖った角や細い突起を、Close は小さな穴やへこみを消す。vdbreshapesdf の Open は箱の辺を円弧で丸めた（実験196〜199）。

VEXとプログラム

点や面をひとつずつ触るための言葉。短い式で書く場面が多い。

VEXpressionべっくすぷれっしょん
attribwrangle などの欄に書く短い VEX。点ごと・面ごとに1回ずつ走り、その要素の値を書き換える。関連: VEX, ランオーバー
ランオーバー / Run Overランオーバー
書いた式を、どの単位で回すかの指定。点ごと・面ごと・頂点ごと・全体で1回、から選ぶ。これを間違えると、同じ式でも結果が変わる。
@ptnumアットピーティーナム
いま処理している点の番号。0 から始まる。番号で処理を分けたいときに使う。関連: ポイント番号
@numptアットナムピーティー
点の総数。@ptnum / @numpt とすれば、0 から 1 に伸びる割合が作れる。
@Pアットピー
その点の位置。3つの成分を持つ。これを書き換えることが、形を変えるということ。
@Nアットエヌ
その点の法線。向いている方向を表す。押し出しや、向きを揃えた複製に使う。関連: 法線
@Cdアットシーディー
その点の色。3つの成分を持つ。値を目で確かめたいとき、いちばん手軽な出し先になる。
@vアットブイ
その点の速度。シミュレーションはこれを見て動かす。手で入れた速度を初速にすることもできる。関連: 速度
f@ / i@ / v@ / s@がたしてい
新しいアトリビュートを作るときに、種類を前に書く決まり。f は小数、i は整数、v は3成分、s は文字。書かないと、意図と違う種類で作られることがある。
point() 関数ポイントかんすう
別の形や別の点から値を読む関数。入力番号・アトリビュート名・点番号を渡す。近くの点を調べるときの基本。
setpointattrib()セットポイントアトリブ
他の点の値を書き換える関数。自分以外を触るときに使う。同じ点を複数から書くと、どれが残るか決まらない。
chf() / chv()チエフ・チブイ
ノードのつまみの値を式の中から読む関数。これで書くと、画面のつまみで調整できるようになる。
nearpoints()ニアポインツ
ある位置の近くにある点を、近い順に集める関数。周りを見て決める処理の土台になる。
並列実行 / Parallelへいれつじっこう
VEX は点ごとに同時に走る。そのため「1つ前の点の結果を使う」ような書き方は当てにできない。順番が要るときは、全体で1回まわす。関連: ランオーバー
バインド / Bindバインド
VOP の中で、形が持っているアトリビュートを取り込む箱。名前を指定して、値を式の流れに引き入れる。関連: VOP
noise()ノイズかんすう
なめらかに変わる乱数。0〜1 の真ん中に固まり、実測では 0.06〜0.92 にしか届かなかった（100万点、実験135）。マスクに使うなら fit で伸ばす。
snoise()エスノイズ
0 を中心にした、符号付きのノイズ。−1〜1 に収まらず、実測で −1.95〜2.28 まで出た（実験135）。
anoise()エーノイズ
ノイズの絶対値を重ねた、尾根のような模様のノイズ。0 の側に寄り、平均は約0.13（実験135）。
xnoise() / onoise()エックスノイズ
noise() の別の作り方。xnoise は 0〜1 の真ん中寄り、onoise は 0 を中心に −1〜1 近くまで出る（実験135）。
flownoise()フローノイズ
時間とともに渦のように流れて見えるノイズ。位相が 0 のときは noise() と同じ値になった（実験135）。
curlnoise()カールノイズ
渦を巻くベクトルのノイズ。湧き出しも吸い込みも無い流れになるので、煙や粒をそれらしく動かせる。
rand()ランドかんすう
入力から決まる乱数（0〜1 の一様）。同じ入力なら同じ値。点番号や位置を渡して、点ごとに違う値を作る。
fit()フィットかんすう
値の範囲を別の範囲に直す。元の範囲の外は端で止まる（クランプ、実験137）。
efit()イーフィット
fit() と同じく範囲を直すが、範囲の外も比例で伸ばす（止まらない、実験137）。
fit01()フィットゼロイチ
0〜1 の値を、指定の範囲に直す。fit(x, 0, 1, 下, 上) と同じで、外では止まる。
clamp()クランプ
値を下限と上限の間に収める。はみ出した分は端の値になる。
lerp()ラープ
2つの値を割合で混ぜる（線形補間）。割合が 0〜1 の外なら、止まらずに伸びる（実験137）。関連: 線形補間
smooth()スムーズかんすう
端でなめらかに止まる 0〜1 の曲線。0〜1 の中では 3x² − 2x³ と一致した（実験137）。関連: スムーズステップ
pcfind()ピーシーファインド
近くの点の番号を、近い順に配列で返す。nearpoints() と同じ結果になった（自分を含む、実験136）。
xyzdist()エックスワイズィーディスト
ある位置から、いちばん近い面までの距離を返す。面の番号と面の上の位置（uv）も受け取れる。
primuv()プリムユーブイ
面の番号と面の上の位置（uv）を渡して、そこでの属性の値を補間して読む。xyzdist() と組で使う。
pcfilter()ピーシーフィルター
pcopen で開いた点群から、近い点ほど重くした平均を返す関数。pcfind・nearpoints より約1.6倍遅く、重みの形は点の並びで変わった（実験181・182）。
@Timeアットタイム
wrangle の中で使える、いまの時刻（秒）。@Frame はフレーム番号。@Time を式に入れると、再生するだけで形が動く（実践「水たまりに雨の波紋」）。
orient 属性オリエントぞくせい
点ごとの向きを表す値（クォータニオン、4つの数）。copytopoints は、点に orient があるとコピーをその向きに回す。quaternion(maketransform(前, 上)) で作れる（実践「鎖を垂らす」）。
qmultiply()キューマルチプライ
2つの回転（クォータニオン）を掛け合わせて、続けて回した向きにする関数。POP で毎ステップ p@orient = qmultiply(p@orient, quaternion(回す軸と角度)) とすると、粒が少しずつ回り続ける（実践「桜の花びらが舞い散る」）。
addpoint() / addprim()アッドポイント / アッドプリム
VEX で点（addpoint）や面・線（addprim）を新しく作る関数。作った点の番号が返るので、それを addprim に渡して線でつなぐ。Run Over を Detail にして、for ループの中で使うことが多い（VEX 解説のお手本 5）。
removeprim() / removepoint()リムーブプリム / リムーブポイント
VEX で面（removeprim）や点（removepoint）を消す関数。removeprim の最後の引数を 1 にすると、使われなくなった点も一緒に消える（VEX 解説のお手本 4）。
ch()チャンネル
VEX のコードから、ノードのつまみの値を読む関数。ch("height") と書いて VEXpression の欄の右上のボタンを押すと、height というつまみが Wrangle に付く。数字をコードに直接書かずに、あとからスライダーで調整できる。
volumesample()ボリュームサンプル
ボリューム（升目の値）から、好きな位置の値を読む関数。升の間は近くの升から混ぜて返す。実験204 では、キャッシュを読み戻した値と元の値の差を、これで升ごとに取った。
setprimintrinsic()セットプリムイントリンシック
面やボリュームが内側に持っている値（intrinsic）を VEX で書き換える関数。VDB の vdb_is_saved_as_half_float を 1 にすると、ファイルに 16 bit で書かれる（実験204）。

数と向き

位置・向き・回転・ノイズを支える言葉。

ベクトル / Vectorベクトル
向きと大きさをまとめて持つ数の組。位置・法線・速度はすべてこれ。3つの成分で表す。
正規化 / Normalizeせいきか
ベクトルの長さを1に揃えること。向きだけを使いたいときに通す。法線は正規化してあるのが前提の場面が多い。
内積 / Dot Productないせき
2つの向きがどれくらい同じ方を向いているかを表す数。同じ向きで1、直角で0、逆で-1。上を向いている面だけ選ぶ、といった判定に使う。
外積 / Cross Productがいせき
2つの向きの両方に直角な向きを求める計算。面の法線を自分で作るときに使う。
クォータニオン / Quaternionクォータニオン
回転を4つの数で表すやり方。角度で表すより、混ぜたときに素直に補間できる。実験053・054で、皮の変形の違いに関わった。関連: オイラー角
回転順序 / Rotate Orderかいてんじゅんじょ
3つの角度をどの軸から掛けるかの並び。Houdini の xyz は「x を先、次に y、最後に z」で、行列では Rz·Ry·Rx になる。同じ角度でも並びが違えば行き先が変わる（実験103で最大 約42.5°）。角度が1つだけなら関係ない。関連: オイラー角, 行列
オイラー角 / Euler Angleオイラーかく
回転を3つの角度で表すやり方。人には分かりやすいが、順番によって結果が変わり、特定の姿勢で破綻する。関連: クォータニオン
行列 / Matrixぎょうれつ
移動・回転・拡大をまとめて表す数の並び。パックした形やインスタンスは、この形で置き場所を持つ。
線形補間 / Lerpせんけいほかん
2つの値のあいだを、まっすぐな割合で混ぜること。0 で片方、1 でもう片方になる。
スムーズステップ / Smoothstepスムーズステップ
端で緩やかに始まり、緩やかに終わる混ぜ方。まっすぐな補間より、見た目が自然になる。
ランプ / Rampランプ
0から1の入力を、好きな色や数に置き換える変換表。温度から炎の色を作るときなどに使う。関連: rampparm
乱数の種 / Seedらんすうのたね
でたらめな値の出し方を決める数。同じ種なら毎回同じ結果になる。比べる実験では、ここを固定する。
オクターブ / Octaveオクターブ
ノイズを重ねる回数。粗い揺れの上に細かい揺れを重ねていく。増やすほど細部が出るが、計算も増える。実験004で、数と見た目の関係を測った。関連: フラクタル, ラキュナリティ
ラキュナリティ / Lacunarityラキュナリティ
ノイズを重ねるとき、1段ごとに何倍細かくするか。既定は2前後。大きくすると、粗さと細かさの差が開く。関連: オクターブ
パーリンノイズ / Perlin Noiseパーリンノイズ
なめらかに変わる定番のノイズ。地形や雲の下地に使う。格子に沿った癖が少し出る。関連: ワーリーノイズ
ワーリーノイズ / Worley Noiseワーリーノイズ
点をばらまいて、最も近い点までの距離から作るノイズ。細胞やひび割れのような模様になる。実験005で並べて比べた。関連: パーリンノイズ
フレームレート / FPSエフピーエス · Frames Per Second
1秒を何枚の絵で表すか。既定は24。同じフレーム数でも、これが違えば実時間は変わるので、速さを測るときは押さえておく。
一様分布 / Uniform Distributionいちようぶんぷ
範囲の中のどの値も、同じ出やすさで出る乱数の出方。0〜1 の一様分布なら、平均は 0.5、分散は 1/12。
正規分布 / Normal Distributionせいきぶんぷ
平均のまわりに多く集まり、離れるほど出にくくなる釣り鐘形の出方。平均と標準偏差の2つで形が決まる。
平均 / Meanへいきん
値を全部足して、個数で割ったもの。実験では、ずれや距離の代表値としてよく使う。
分散 / Varianceぶんさん
値が平均からどれだけ散らばっているか。平均との差を2乗して平均したもの。
標準偏差 / Standard Deviationひょうじゅんへんさ
分散の平方根。元の値と同じ単位で、散らばりの大きさを表す。
弧長 / Arc Lengthこちょう
曲線に沿って測った長さ。細かく折れ線で近づけるほど、本当の長さに近づく。
らせん / Helixらせん
円を回りながら一定の割合で上がっていく線。1巻きの長さは、円周と上がる高さを2辺とする直角三角形の斜辺になる。
ピッチ / Pitchピッチ
らせんやねじが、1巻きで進む距離。
収束 / Convergenceしゅうそく
細かくしたり回数を増やしたりしたとき、結果がある値に落ち着いていくこと。どこで落ち着くかを見れば、必要な細かさが分かる。
外挿 / Extrapolationがいそう
測った範囲の外を、傾向から推し量ること。範囲の中を埋める補間より当たりにくい。
相対誤差 / Relative Errorそうたいごさ
ずれの大きさを、正しい値に対する割合で表したもの。大きさの違うものどうしの精度を比べられる。
オイラーの多面体定理 / Euler's Formulaオイラーのためんたいていり
穴の無い閉じた多面体では、点の数 − 辺の数 + 面の数 = 2 になる。三角形分割の面の数を先に計算するのに使える。
ユークリッド距離 / Euclidean Distanceユークリッドきょり
2点を結ぶまっすぐな線の長さ。√(x²+y²+z²)。ふつう「距離」と言えばこれ。
マンハッタン距離 / Manhattan Distanceマンハッタンきょり
縦と横にしか進めないときの道のり。|x|+|y|。碁盤の目の街を歩く距離にたとえた名前。斜め45°の向きでは、まっすぐの距離の約1.41倍になる。
測地線距離 / Geodesic Distanceそくちせんきょり
面の上から離れずに進んだときの最短距離。球の上なら大円に沿った弧の長さ。関連: ユークリッド距離
最短経路 / Shortest Pathさいたんけいろ
網の辺をたどって2点を結ぶ道のうち、いちばん短いもの。辺の向きに縛られるので、面の上のまっすぐな距離より長くなることがある。
ダイクストラ法 / Dijkstra's Algorithmダイクストラほう
網の辺をたどって、ある点から他の全部の点までの最短経路を求めるやり方。近い点から順に確定していく。
熱測地線法 / Heat Methodねつそくちせんほう
始まりの点から熱が広がる様子を計算し、その向きから面の上の距離を求めるやり方。網の向きに左右されにくい。
エルミート補間 / Hermite Interpolationエルミートほかん
両端の値だけでなく、両端の傾き（速度）も使ってつなぐ補間。位置と速度が分かっていれば、2次の動きは誤差0でつながる。関連: 補間, 線形補間
標準誤差 / Standard Errorひょうじゅんごさ
たくさんの値の平均が、偶然でどれくらいぶれるかの目安。標準偏差 ÷ √（個数）。10万個なら、標準偏差の約1/316。関連: 標準偏差
指数分布 / Exponential Distributionしすうぶんぷ
0 に近い値がいちばん出やすく、大きい値ほど出にくくなる乱数の出方。待ち時間や寿命のばらつきに使われる。
ベルヌーイ分布 / Bernoulli Distributionベルヌーイぶんぷ
2つの値のどちらかが、決めた確率で出る乱数の出方。attribrandomize の Two Values がこれ。
パップス・ギュルダンの定理 / Pappus's Theoremパップスギュルダンのていり
断面を軸のまわりに回してできる形の体積は、断面の面積 × 断面の重心が回る長さ、になるという定理。ドーナツの体積がすぐ出せる。
弦 / Chordげん
曲線の上の2点を結ぶまっすぐな線。細かく割った折れ線は、弦をつないだものなので、元の曲線より少し短い。関連: 弧長
等脚台形 / Isosceles Trapezoidとうきゃくだいけい
平行な2辺を持ち、残りの2辺の長さが等しい四角形。円錐台を多角形で近似したときの側面の1枚がこれになる。
k 角形の面積 / Area of a Regular Polygonけいかくけいのめんせき
半径 r の円に内接する正 k 角形の面積は (k/2)·r²·sin(2π/k)。円の面積 πr² より少し小さく、k を増やすと近づく。
外接球 / 外接半径 / Circumradiusがいせつきゅう
多面体のすべての頂点を通る球と、その半径。platonic の Radius は、四面体・八面体・二十面体ではこの半径だった（実験142）。
正多面体 / Platonic Solidせいためんたい
すべての面が同じ正多角形で、どの頂点にも同じ数の面が集まる立体。四面体・立方体・八面体・十二面体・二十面体の5つだけ。
内接多角形 / Inscribed Polygonないせつたかくけい
頂点がすべて円の上にある多角形。辺は円の内側を通るので、面積も周も円より少し小さい。円や円柱の Polygon はこの形（実験143・148）。
球帯の面積 / Archimedes' Hat-Box Theoremきゅうたいのめんせき
球を平行な2つの面で切った帯の面積は、高さ h だけで決まり 2πRh になる。clip で切った球で確かめた（実験146）。
せん断 / Shearせんだん
層をずらすように、位置に比例して横へ動かす変形。体積は変わらない（実験147）。
テーパー / Taperテーパー
片側へ行くほど細く（または太く）する変形。twist SOP の Taper と Linear Taper は、Strength = 1 で何もしない（実験147）。
トーラス / Torusトーラス
ドーナツの形。面積 4π²Rr、体積 2π²Rr²（R は輪の半径、r は管の半径）。
後退差分・中心差分・前進差分こうたいさぶん
となりの時刻との差で速さを見積もる方法。後退は今と1つ前、前進は今と1つ後、中心は前後の平均。動きが加速しているとき、中心差分だけが半フレームずれない（実験159）。
変動係数 / Coefficient of Variationへんどうけいすう
標準偏差 ÷ 平均。大きさの違うもの同士のばらつきを比べるのに使う。0 なら全部同じ大きさ（実験158）。
二項分布 / Binomial Distributionにこうぶんぷ
確率 p で当たるくじを N 回引いたときの当たりの数の分布。平均 Np、ばらつきの幅（標準偏差）は √(Np(1−p))。scatter の点の割り振りのばらつきがこの幅くらいだった（実験155）。
発散 / Divergenceはっさん
流れがその場所から湧き出しているか（プラス）、吸い込まれているか（マイナス）を表す量。∂vx/∂x + ∂vy/∂y + ∂vz/∂z。curlnoise はほぼ 0 だった（実験171）。
湧き出しのない流れ / Divergence-Freeわきだしのないながれ
発散がどこでも 0 の流れ。流されたものは詰まりも薄まりもしない。curlnoise で流した粒は、まわりの粒の数がほぼ保たれた（実験172）。
半陰的オイラー法 / Semi-Implicit Eulerはんいんてきオイラーほう
1ステップで、先に速さを足し、その新しい速さで位置を進めるやり方。POP の粒の落下がこの形に合った（実験165）。
終端速度 / Terminal Velocityしゅうたんそくど
重力と空気の抵抗が釣り合って、それ以上速くならない落ちる速さ。POP の抵抗では √(g/k) に近づいた（実験166）。
速さの2乗に比例する抵抗 / Quadratic Dragはやさのにじょうにひれいするていこう
速さ（風との差）の2乗に比例する抵抗。差が半分になるまでの時間が、だんだん延びる。popwind の粒の近づき方がこの形だった（実験175）。
円の当てはめ / Circle Fitえんのあてはめ
散らばった点にいちばん合う円を、最小二乗で求めること。x² + y² を x・y・1 の組み合わせで表す Kasa 法がいちばん簡単。Open で丸めた辺の断面の半径を、これで測った（実験198）。
角錐台 / Frustum of Pyramidかくすいだい
角錐の上を平らに切り落とした形。体積は h/3 × (下の面積 + 上の面積 + √(下 × 上))。polyextrude の Inset で押し出した形がこれだった（実験192）。
ラプラシアン平滑化 / Laplacian Smoothingラプラシアンへいかつか
点を、となりの点の平均へ少しずつ寄せてならす処理。形全体も縮む。smooth の縮み方は 1/(1 + Strength·…) の形で、ゼロまでは縮まなかった（実験185〜187）。
懸垂線 / Catenaryけんすいせん
鎖やロープの両端を持ったとき、自分の重さで垂れてできる曲線。高さは a · cosh(x / a) の形で、a が小さいほど深くたるむ。a = 0.9 で幅 2 m の真ん中が 0.62 m、a = 0.5 で 1.38 m 下がった（実践「鎖を垂らす」）。
波長 / Wavelengthはちょう
波の山から次の山までの長さ。sin で波を作るときは sin(2π × 距離 / 波長) と書く。網の升が波長に比べて大きいと、点が山と谷を飛び越えて波が描けない。
黄金角 / Golden Angle（葉序）おうごんかく（ようじょ）
約 137.5度。1つずつこの角度だけ回して、中心からの距離を √番号 に比例させて並べると、ひまわりの種のようにすき間なく詰まる。140度にするだけで、となりの粒までの平均距離が 5.80 mm から 1.59 mm に縮み、粒が線の上に固まった（実践「ひまわりを咲かせる」）。
モジュール（歯車）/ Moduleモジュール
歯車の歯の大きさを表す数。直径 = モジュール × 歯の数。モジュールがそろった歯車どうしはかみ合い、中心の距離は モジュール × (歯の数1 + 歯の数2) ÷ 2 になる（実践「歯車をかみ合わせて回す」）。
ベールの法則 / Beer–Lambert Lawベールのほうそく
光が煙や色水の中を進むと、進んだ距離に応じて一定の割合ずつ減る、という式。届く割合 T = exp(−濃さ × 距離 × 係数)。Karma の煙では係数が 1（1 m あたり）で、Density Scale と厚みは掛け算で効いた。Density Scale を倍にすると T は 2 乗になる（実験216）。

シミュレーション

時間を進めながら計算するもの。1フレーム目の結果を使って2フレーム目を計算するため、途中から飛ばして見ることができない。

シミュレーション / Simulationシミュレーション
物理法則にもとづいて動きを計算させること。手で動きを付けるのではなく、条件を与えて結果を計算させる。略してsimとも書く。
ソルバ / Solverソルバ
シミュレーションの計算を担当するノード。剛体用、布用、煙用など対象ごとに専用のソルバがある。
RBDアールビーディー · Rigid Body Dynamics
変形しない硬い物体の物理計算。積み木が崩れる、壁が砕けて飛び散る、といった動きを担当する。関連: voronoi fracture
Vellumベラム
布、ゴム、髪のような柔らかいものを扱うソルバ。比較的軽く扱いやすいため、柔らかいものを試すならまずここから。
Pyroパイロ
煙と炎を扱うソルバ。ボリュームとして計算するため、面のモデリングとは考え方がかなり違う。関連: ボリューム
FLIPフリップ · Fluid-Implicit-Particle
液体を扱うソルバ。液体をパーティクルとして計算し、最後に表面を張って水面にする。
サブステップ / Substepsサブステップ
1フレームの中を何回に分けて計算するかの設定。動きが速すぎて突き抜けてしまうときに増やす。増やすと正確になるが時間もかかる。
キャッシュ / Cacheキャッシュ
計算結果をファイルに保存しておくこと。シミュレーションは重いため、一度計算したら保存して使い回すのが前提。file cache ノードで行う。
フレーム / Frameフレーム
アニメーションの1コマ。24フレームで1秒が一般的。シミュレーションはフレームを順に進めながら計算する。
フラクチャ / Fractureフラクチャ
ひとつの形を破片に割ること。割った時点ではまだ動かない。動かすのはソルバの仕事で、割る工程と動かす工程は分かれている。関連: RBD / voronoi fracture
コンストレイント / Constraintコンストレイント
点と点のつながり方の規則。布なら「この点とこの点は離れすぎない」という条件にあたる。Vellum では規則を作るノードと、それを解くソルバが別になっている。関連: Vellum
スティフネス / Stiffnessスティフネス
伸びにくさ・曲がりにくさ。Vellum では「値 × 10の指数乗」で決まるため、見えている値より指数のほうが効く。実験015で、値と指数を入れ替えた組み合わせが同じ結果になることを確かめた。関連: コンストレイント
ピン / Pinピン
シミュレーション中も動かさないよう固定した点。布の上端を留めて垂らす、といった使い方をする。対象の指定を空にすると「全部が対象」と解釈され、何も動かなくなる。関連: コンストレイント
密度 / Densityみつど
煙の濃さを表す値。ボリュームのマス目ひとつひとつに入っている数値で、全部足したものが煙の総量にあたる。煙のシミュレーションで保存量として測れるのはこれ。関連: ボリューム / ボクセル
散逸 / Dissipationさんいつ
煙を毎フレーム減らす設定。値を d とすると、毎フレーム (1−d) 倍になる。発生源が供給し続ける場合は減り続けるのではなく、やがて 1/d のところで釣り合う。関連: Pyro / 密度
発生源 / Sourceはっせいげん
煙や液体が湧き出してくる場所。ソルバは毎フレーム、ここから新しい分の供給を受け取る。供給が続く限り総量は増え続ける。関連: Pyro / FLIP
パーティクル / Particleパーティクル
位置と速度を持つだけの点。面を持たないので軽く、大量に扱える。火花・雨・砂・群衆のように「小さなものがたくさん動く」表現に使う。液体も内部では粒として計算される。関連: POP / FLIP
narrow band / ナローバンドナローバンド
液体の計算を軽くする仕組み。水面の近くだけを粒で表し、深いところはボリュームで扱う。既定で有効なので、水を深くしても粒の数はほとんど増えない。粒の数を水の量の目安に使いたいときは切る必要がある。関連: FLIP
reseeding / リシードリシード
粒を足したり間引いたりして数を一定に保つ仕組み。名前から「増やすもの」と思いがちだが、実測では切ると40フレームで36%増えた。減らす側も担っている。関連: FLIP / パーティクル
空気抵抗 / Air resistanceくうきていこう
物が空気の中を進むときに受ける、進む向きと逆の力。速さに比例する形（線形抵抗）と、速さの2乗に比例する形（二乗抵抗）がある。Houdini はどちらのソルバでも二乗抵抗だった。POP の popwind の airresist（実験029）も、MPM の mpmsolver の Air Drag（実験066）も、速さの2乗に比例している。MPM のほうは3次元の相対速度の大きさで決まるので、横風が落ちる速さまで変える。
加速度 / Accelerationかそくど
速さが1秒あたりどれだけ増えるか。popforce に 3 と入れると加速度が 3 になり、1秒で速さ3、2秒で速さ6と伸び続ける。上限は無い。
glue / 接着グルー
離れたピースどうしを、近さを頼りにくっつける拘束。Houdini の Vellum では stitch という型の拘束が作られる。力がかかると外れる設定（breaking）が使えるので、「狙った線で破れる」を作るときはここを使う（実験031）。
応力 / Stressおうりょく
拘束1本にどれだけの力がかかっているか。Vellum では拘束のプリミティブに stress として書かれる。ただし solver の normalizestress を切ると値が 566分の1 になるので、数字だけを見るときは設定も一緒に記録する（実験031）。
終端速度 / Terminal velocityしゅうたんそくど
落ちる物が、重力と空気抵抗がつり合って、それ以上速くならなくなる速さ。二乗抵抗なら √(重力 ÷ 抵抗の係数)。MPM の Air Drag を 4.0 にすると式は 1.566046、実測は 1.607434 だった（実験066）。関連: 空気抵抗 / Air resistance
Ground Plane（MPM）グラウンドプレーン
mpmsolver が最初から持っている地面。groundactive が既定で 1 なので、コライダを一つも置かなくても粒は y = 0 で止まる。自由落下を測りたいときは切る（実験066）。関連: MPM / コライダ
Wind Velocity（MPM）ウィンドベロシティ
mpmsolver の風速。ただし風は空気抵抗を通してしか効かないので、Air Drag が既定の 0 のままだと、風速をいくら上げても位置も速度も9桁まで変わらない（実験066）。関連: 空気抵抗 / Air resistance / MPM
クーロン摩擦 / Coulomb frictionクーロンまさつ
「摩擦力は押しつける力に比例し、速さには関係しない」という一番よく使われる摩擦の見立て。止まるまでの距離は 初速² ÷ (2 × μ × 重力)。MPM の Ground Friction はこの μ そのもので、摩擦 0.25 のとき式 3.261978 に対し実測 3.260808 だった（実験067）。ただし摩擦が強いと塊が潰れて、式から外れていく。関連: 摩擦 / MPM
Sticky（MPM）スティッキー
mpmsolver やコライダの粘着。横に滑るぶんにはほとんど効かず（0.5 と 1.0 が6桁まで同じ値）、落として跳ねさせると効く。跳ね返る高さが 0.026922 から 0.013617 へ半分になる。「押しつけている間」ではなく「離れようとした瞬間」に働く数字（実験067）。関連: Ground Plane（MPM） / MPM
サブステップ / Substepサブステップ
1フレームを内部で何回に刻んで計算するか。増やすと細かい動きやぶつかりを拾えるが、そのぶん時間もかかる。実験064では、刻みを増やすと結果が変わることを測った。関連: CFL条件
CFL条件 / CFL Conditionシーエフエルじょうけん
1回の刻みで、ものが升目1つ以上を飛び越えないようにする決まり。速く動くものがあるほど、刻みを細かくする必要が出る。関連: サブステップ
減衰 / Dampingげんすい
動きを少しずつ弱める働き。入れないと、揺れがいつまでも続いて止まらない。
剛性 / Stiffnessごうせい
形を保とうとする強さ。高いと硬く、低いとふにゃふにゃになる。布や柔らかい物で最初に触るつまみ。
静止摩擦 / Static Frictionせいしまさつ
止まっているものが滑り出すまでの抵抗。坂の傾きが摩擦の値を超えると滑り出す。実験067では、その境目が理屈通りに出るかを測った。関連: 動摩擦
動摩擦 / Dynamic Frictionどうまさつ
滑っている間にかかる抵抗。静止摩擦より小さいことが多い。滑り出したあとの減り方を決める。関連: 静止摩擦
反発係数 / Bounceはんぱつけいすう
ぶつかったあとにどれくらい速度が残るか。1 で跳ね返り続け、0 で止まる。
粘性 / Viscosityねんせい
液体の流れにくさ。高いと蜜のように、低いと水のように動く。実験068で、見た目がどこで切り替わるかを測った。
表面張力 / Surface Tensionひょうめんちょうりょく
液体が表面を小さくまとめようとする働き。粒が玉になったり、糸を引いたりする見た目をつくる。
質量 / Massしつりょう
動かしにくさ。同じ力をかけても、重いほど加速しない。粒には pscale や density から自動で決まることもある。
慣性 / Inertiaかんせい
いまの動きを続けようとする性質。回転では、重さの散らばり方（慣性モーメント）で回りにくさが変わる。
角速度 / Angular Velocityかくそくど
1秒あたりにどれだけ回るか。実験071では、この値がある大きさを超えると物が飛び出すことを測った。
拘束 / Constraintこうそく
2つの物のあいだの決まり。離れないようにしたり、角度を保ったり、ある力を超えたら外れたりする。破壊の見た目はここで決まる。関連: グルー
グルー / Glueグルー
破片どうしをくっつけておく拘束。決めた強さを超える力がかかると外れる。強すぎると壊れず、弱すぎると自分の重さで崩れる。関連: 拘束
剛体 / Rigid Bodyごうたい
形が変わらない硬い物。位置と向きだけを持つので、計算は軽い。関連: RBD
ソフトボディ / Soft Bodyソフトボディ
押すと形が変わる柔らかい物。中身まで持つので、剛体より重い。
粒子分離 / Particle Separationりゅうしぶんり
粒と粒のあいだの間隔。小さくすると細かく見えるが、粒の数は3乗で増える。実験078で、間隔と時間の関係を測った。関連: ボクセルサイズ
グリッドスケール / Grid Scaleグリッドスケール
粒の間隔に対して、計算に使う升目を何倍にするか。粒より升目が粗いと、細かい動きが丸められる。
発散 / Divergenceはっさん
ある場所から湧き出している量。液体では、これを0に保つことで体積が変わらないようにしている。
初期状態 / Initial Stateしょきじょうたい
計算を始めるときの形と速度。ここが違うと、あとの結果もすべて変わる。比べる実験では、まずここを揃える。
安息角 / Angle of Reposeあんそくかく
砂や土が崩れずに保てる一番急な傾き。これより急にすると崩れて落ちる。地形の slump で使う。
弾性 / Elasticityだんせい
力を抜くと元の形に戻る性質。実験062では、この強さを変えると跳ね方が変わることを見た。
塑性 / Plasticityそせい
力を抜いても形が戻らない性質。粘土や雪のように、へこんだままになるものはこれを持つ。
ヤング率 / Young's Modulusヤングりつ
引っぱったときの伸びにくさ。大きいほど硬い。MPM で材質を決めるときに出てくる。
ポアソン比 / Poisson Ratioポアソンひ
引っぱったときに、横がどれくらい細くなるか。0.5 に近いと体積を保ち、0 に近いと細らない。
マイクロソルバ / Microsolverマイクロソルバ
1つの仕事だけをする小さな解き手（運ぶ・減らす・ぼかす・浮かせる など）。Pyro や FLIP の中身は、これらの組み合わせでできている。
移流 / Advectionいりゅう
流れに乗って、濃さや温度が運ばれること。煙のシミュレーションで毎ステップ行う、いちばん基本の計算。
浮力 / Buoyancyふりょく
まわりより軽い（熱い）ものが浮き上がる力。煙の計算では、温度の高い所に上向きの速度を足して表す。
渦度の閉じ込め / Vortex Confinementうずどのとじこめ
計算の途中でなまって消えてしまう小さな渦を、回転を強めて取り戻す工夫。煙の細かさを保つ。
燃焼 / Combustionねんしょう
燃料が燃えて、熱と煙と気体を出すこと。Pyro では、発火温度を超えた所で燃料を減らし、温度を上げて表す。
発火温度 / Ignition Temperatureはっかおんど
燃料が燃え始める温度。これより低い所では、燃料があっても燃えない。
スート / Sootスート
燃えたあとに出る煤（すす）の煙。Pyro では density とは別に、黒い煙として扱うことがある。
温度場 / Temperature Fieldおんどば
場所ごとの温度を持つボリューム。浮力の強さや、炎の色（黒体放射）を決める。
速度場 / Velocity Fieldそくどば
場所ごとの流れの向きと速さを持つボリューム（vel）。これに乗って、煙の濃さや温度が運ばれる。
圧力投影 / Pressure Projectionあつりょくとうえい
流れが「どこでも湧き出さない・吸い込まない（発散0）」ようにする計算。煙や水が縮んだり増えたりしないようにする要。関連: 発散
拘束の反復回数 / Constraint Iterationsこうそくのはんぷくかいすう
Vellum で、1ステップの中で拘束（伸び・曲げなど）を直す回数。増やすと布が伸びにくくなる。Substeps を増やすより安く伸びを抑えられた（実験177）。
めり込み / Penetrationめりこみ
ぶつかった物どうしが、止まる前に互いの中へ入り込むこと。Bullet では Substeps が少ないほど深く、1 で 0.38 めり込んだ（実験183）。
生まれる割合 / Birth Rateうまれるわりあい
粒を1秒あたりに生む数。1フレームに割り切れない端数は、フレームごとに運で決まる（実験193）。
粒の寿命 / Lifeつぶのじゅみょう
粒が生まれてから消えるまでの秒数。数えられるフレームは Life × fps − 1/Substeps で、Substeps 1 では 1 フレーム短い（実験193・194）。
active 属性アクティブぞくせい
RBD（Bullet）で、その塊を動かすかどうかを決める点の値。0 にすると、ぶつかられても動かない壁のようになる。窓枠にはまったガラスの縁の破片を止めるのに使った（実践「窓ガラスを割る」）。
拘束の強さ / Strengthこうそくのつよさ
破片どうしをくっつけておくつながり（Glue）が、どれだけの衝撃で切れるか。小さいほど広く割れる。同じ場面で 0.8 なら 41 個、5 以上なら 0 個の破片が動いた（実践「窓ガラスを割る」）。
インパルス発生 / Impulse Activationインパルスはっせい
popsource で、決めたフレームに一度にまとめて粒を生む仕組み。Emission Type が All Points のときは、Activation が 1 のフレームごとに全部の点から生まれるので、1 フレーム目だけ生むなら式 $FF == 1 を入れる（実践「花火を打ち上げる」）。
当たりの余白 / Collision Marginあたりのよはく
Bullet（RBD）が、形のまわりに付ける当たり判定の余白。既定の 0.02 のままだと、厚さ 1.8 mm のコインが床から 2 cm 近く浮いて止まった。0.0005 にすると床に寝た。薄い物・小さな物では小さくする（実践「コインをばらまく」）。
粒を面にする / Surfacingつぶをめんにする
FLIP などの粒の集まりから、水の表面の多角形を作ること。particlefluidsurface で行う。形は Influence Scale（粒の影響の広さ）と Method で大きく変わり、なめらかにするには Filtering を入れる（実験208）。
Neural Point Surfaceニューラルポイントサーフェス
Houdini 21 の particlefluidsurface に入った、学習済みのモデルで粒から面を作る方法（Method の 3 つ目）。ダムブレイクでは既定の 1.6 倍の時間で、形は既定とフィルタを入れたものの間くらいだった。最初に使うときだけ読み込みの時間が余分にかかる（実験208）。
曲げの硬さ / Bend Stiffnessまげのかたさ
Vellum の布が折れ曲がりにくい度合い。vellumconstraints の Cloth では Stiffness × 10 の指数で決め、既定は 0.1。テーブルクロスでは 0.1 より下げても形がほぼ同じで、10 以上にすると布が板のように張って机から張り出した（実験217）。
波の設計図 / Ocean Spectrumなみのせっけいず
海の波を「どの長さの波が、どれだけの高さで、どちらへ進むか」の混ざり方で表したもの。oceanspectrum で風の強さと向きから作り、oceanevaluate が点をその通りに動かす。シミュレーションしなくても海が作れる。
うねり / Swellうねり
遠くの風で生まれて、長い距離を旅してきた、長くなだらかな波。沖の海は、うねりの上に、その場の風の波とさざ波が乗っている。実践「夕暮れの海」では、Grid Size 300 m の設計図をうねり、37 m を風の波、4.3 m をさざ波にして重ねた。
砕波（さいは）/ Breaking Waveさいは
沖から来た波が浅い所で高く切り立ち、崩れて白い泡になること。砂浜では、崩れる所から岸までが白い泡の帯になる。実践「冬の朝の七里ヶ浜」では、シミュレーションせずに、attribwrangle で「岸へ進む波の列」を足し、崩れる所（沖 27〜41 m）から岸までに泡の色を付けた。
白波 / Whitecapしろなみ
沖で風に押された波の頭が崩れて、白く泡立つもの。本物の海で白波が覆う割合は、風速の 3.4 乗にほぼ比例する（Monahan らの式）。風 5 m/秒で 0.09%、10 m/秒で 1%、15 m/秒で 4%。oceanevaluate の cusp で色を付けるときのしきい値は、実験223 の表で決められる。

3Dの形を表示している画面。ここで見えているものは簡易表示で、レンダリング結果とは異なる。
Smooth Wire Shadedスムース・ワイヤー・シェーデッド
表示モードの一種。面に色を付けたうえで、面の境界線（ワイヤーフレーム）も重ねて描く。分割数やトポロジを確認したいときに有効。関連: トポロジ
ワイヤーフレーム / Wireframeワイヤーフレーム
面を塗らず、辺だけを線で表示すること。形の内部構造や分割数を見るのに使う。
フリップブック / Flipbookフリップブック
ビューポートの表示を連続して画像に書き出し、動きを確認すること。レンダリングせずにアニメーションを見たいときに使う。
距離減衰 / Falloffきょりげんすい
光が遠くなるほど弱くなる性質。ポイントライトは距離の2乗で暗くなるため、遠くに置くと強度を大きく上げないと真っ暗になる。
distant lightディスタント・ライト
太陽のように平行な光を当てるライト。距離による減衰がないため、どこに置いても明るさが変わらない。関連: 距離減衰
dome light / envlightドーム・ライト
シーン全体を包む球から光を当てるライト。全方向から柔らかく照らせるので、形を確認したいときに扱いやすい。
サンプル / Sampleサンプル
1ピクセルの色を決めるために飛ばす光線の本数。多いほどザラつきが減るが時間がかかる。ただし Karma では「ここまで使ってよい」という上限であって、実際に使われる数は収束具合で決まる。関連: Karma / レンダリング
ハードウェアレンダラー / Hardware rendererハードウェアレンダラー
画面表示と同じ仕組みで絵を作る速いレンダラー。OpenGL ROP がこれ。光が物の中を通る計算はしないので、煙のようなものは濃淡だけになり陰影が出ない。関連: OpenGL ROP / Karma
コンタクトシート / Contact sheetコンタクトシート
連続したコマを1枚に並べた画像。動きの全体を一目で見るために使う。動画と違って、止まったまま前後を見比べられる。関連: フリップブック
フラクタル / Fractalフラクタル
大きな模様の中に同じ形の小さな模様が入れ子になっている性質。ノイズを何枚も重ねて自然な凹凸を作るときの重ね方を指す。関連: ノイズ / mountain
黒体放射 / Blackbody radiationこくたいほうしゃ
熱を持ったものが、その温度に応じた色で光る現象。低いと赤、上がるにつれて橙・黄・白へ変わる。焚き火が赤く、溶けた鉄が白っぽいのはこれ。VEXの blackbody(温度, 白とみなす温度) が温度から色を返す。
色温度 / Color temperatureいろおんど
光の色をケルビン（K）という温度の単位で表したもの。ろうそくが約1900K、白熱電球が約2800K、昼光が約6500K。数字が小さいほど赤く、大きいほど青い。
ホワイトバランス / White balanceホワイトバランス
「何色を白とみなすか」の設定。blackbody() の2つ目の引数がこれで、6500 を渡すと 6500K が白になり、それより低い温度は赤寄り、高い温度は青寄りに出る。
アルファ / Alphaアルファ
不透明度。1で完全に不透明、0で完全に透明。Houdiniではポイントの @Alpha に入れる。薄い煙や炎のふちを表すのに使う。
パストレーシング / Path Tracingパストレーシング
光の通り道をでたらめに辿って色を決めるやり方。回数を増やすほど、ざらつきが減って本物に近づく。関連: サンプル, Karma
AOVエーオーブイ · Arbitrary Output Variable
色以外の情報を、絵と一緒に別の層として書き出すもの。深さ・法線・部位ごとの色など。あとで合成するときに使う。
リニア空間 / Linear Spaceリニアくうかん
明るさをそのまま数で表す扱い方。計算はここで行い、画面に出すときに sRGB へ変える。混ぜると色が濁る原因になる。関連: sRGB, ガンマ
sRGBエスアールジービー
画面に出すための明るさの表し方。人の目の感じ方に合わせて曲げてある。計算用のリニアとは別物。関連: リニア空間
ガンマ / Gammaガンマ
明るさの曲げ方を表す数。これが合っていないと、全体が白っぽく、または黒っぽく見える。
露出 / Exposureろしゅつ
全体の明るさを、絞りの段数で上げ下げする指定。1 上げると倍の明るさになる。
アルベド / Albedoアルベド
その物が光をどれくらい返すか。色そのものというより、明るさの返し方を指す。
粗さ / Roughnessあらさ
表面のざらつき。0 に近いと鏡のように映り、大きくすると反射がぼける。実験039で、粗さと見た目の関係を並べて見た。
金属度 / Metallicきんぞくど
金属らしさ。1 に近づけると、地の色が反射の色として出て、白いハイライトが消える。
屈折率 / IORくっせつりつ · Index of Refraction
光がその物に入るときの曲がり方。ガラスは約1.5、水は約1.33。反射の強さもこの値で決まる。関連: フレネル
フレネル / Fresnelフレネル
浅い角度から見ると反射が強くなる現象。水面を遠くから見ると空が映るのがこれ。
サブサーフェス / Subsurfaceサブサーフェス
光が中に入って散らばってから出てくる様子。肌・牛乳・大理石のような、内側が少し光る見た目を作る。
法線マップ / Normal Mapほうせんマップ
面の向きを画像で細かく置き換えるやり方。形は変えずに、凹凸があるように見せる。関連: バンプ, ディスプレイスメント
バンプ / Bumpバンプ
明るさの画像から、凹凸があるように見せるやり方。輪郭は変わらないので、真横から見ると平らだと分かる。
ディスプレイスメント / Displacementディスプレイスメント
画像に従って、面そのものを動かすやり方。輪郭も変わるので本物の凹凸になるが、計算は重い。
HDRIエイチディーアールアイ · High Dynamic Range Image
明るさの幅を広く持った画像。これで周りを囲むと、写真の中にあるような光り方になる。
被写界深度 / Depth of Fieldひしゃかいしんど
ピントが合う奥行きの幅。絞りを開くと狭くなり、前後がぼける。
モーションブラー / Motion Blurモーションブラー
シャッターが開いている間の動きが、ぶれとして写ること。速いものが自然に見える。計算は重くなる。
シーン / Sheenシーン
布や苔のような細かい毛のある表面が、斜めから見たときにふわっと明るく光る見え方。principledshader の Sheen を上げると足せる（実践「苔むした石を作る」「テーブルクロスを掛ける」）。
発光 / Emissionはっこう
表面そのものが光を出すこと。principledshader の Emission Intensity で強さ、Emission Color で色を決める。Use Point Color を入れると点の色 Cd がそのまま光の色になる（実践「花火を打ち上げる」）。
透過色 / Transmission Colorとうかしょく
透ける材質の中を光が通るときに付く色。Transmission Distance の長さを進むと、その色になる。厚い所ほど濃く色づく（ゼリーの赤、板ガラスの縁の緑）。
光の筋 / 薄明光線（God Rays）ひかりのすじ / はくめいこうせん
霧やほこりで満ちた空気に、すき間から日が差したときに見える光の帯。霧が光を横へ散らすので見える。霧を 0 にすると空中の筋は消えた（実践「霧の森に光の筋を差す」）。
ノイズ除去 / Denoiserノイズじょきょ
レンダリングの細かいざらつきを、あとから画像処理で消す仕組み。Karma では Denoiser を OIDN にする。霧のようなボリュームはサンプルを増やしてもざらつきが残りやすいので、そういう絵で使う。
ポイントライト / Point Lightポイントライト
1点から全方向に光を出す明かり。hlight の Light Type を Point にする。電球やろうそくの光に使う。近い物ほど強く照らすので、ろうそくのすぐ上に置くときは Intensity を 0.01 ほどに小さくする（実践「ろうそくの炎をともす」）。
コート / Coatコート
表面の上にもう1枚、透明なつやの層を重ねる設定（principledshader の Coat）。車の塗装・うわぐすり・アイシングのように、下の色の上につやが乗った見え方になる（実践「ドーナツを飾る」「六角形のタイルを敷く」）。
F値 / F-Stopエフち
レンズの絞りの数字。小さいほど、ピントの合った所の前後が大きくぼける。Houdini ではカメラの F-Stop で決め、Karma の Enable Depth of Field を入れたときだけ効く。7 m 先の球で、0.7 では少し、0.2 ではっきりぼけた。ぼけを入れても撮る時間はほとんど延びなかった（実験205）。
シャッター時間 / Shutter Timeシャッターじかん
1 枚の画のために、シャッターを開けておく長さ（フレーム単位）。長いほど、動く物が大きくぶれる。Houdini のカメラの既定は 0.5 フレーム。秒速 12 m の箱で、1 にするとぶれが倍になった。ぶれを入れても撮る時間は数 % しか延びなかった（実験205）。
Noise Level（Karma）ノイズレベル
Karma が画素ごとにサンプルを打ち切る目安。既定 0.01。ざらつきがこれより小さくなった画素は、上限より前に打ち切る。実験205 では、サンプル数の上限を上げてもざらつきは減らず、Noise Level を 0.005・0.0025 に下げると減ったが、時間は約 2 倍・6 倍になった。
Volume Step Rate（Karma）ボリュームステップレート
Karma が煙や炎の中を進むときの細かさ。既定 0.25。大きいほど細かく進む。一様な煙の箱では、1 で光の吸収の式とぴったり合い、0.25 では濃い煙が式より少し明るく（Density Scale 4 で +12%）、0.05 ではほぼ素通りになった（実験216）。焚き火では、0.125 に下げても速くならず、1 に上げると 1920×1080 で 23% 遅かった。見た目の差は見分けられなかった（実験207）。
ハイライト / Highlightハイライト
つやのある物に映った、明かりのいちばん明るい所。金属の球では、Roughness 0.2 まで板の明かりの四角がそのまま映り、0.3 から広がって暗くなった。0.7 で明るさは 0 のときの 15%、広さは 2.4 倍（実験212）。
Subsurface Distanceサブサーフェスディスタンス
principledshader の SSS で、光が物の中を散らばって進む距離（m）。既定 0.1。半径 0.5 の球を逆光で撮ると、0.05 以下ではほとんど透けず、0.3 で真ん中が SSS なしの 5.3 倍明るかった。1 ではかえって暗く、正面からの画も 41% に沈んだ（実験213）。
Random Walk（SSS）ランダムウォーク
principledshader の SSS Mode の 1 つ（Random Walk (Karma)）。光が中で散らばる道のりを 1 歩ずつたどる。同じ Distance 0.1 でも既定の方式よりよく透け（逆光の真ん中 3.8 倍）、正面から見ても暗くならなかった（実験213）。
ぼけの円 / Circle of Confusionぼけのえん
ピントの合っていない点が、画の上で広がって写る円。Karma では直径が f²(d−s)/(N·d·s)（f 焦点距離・N F-Stop・s ピントの距離・d 物までの距離）に 0.9% 以内で一致し、F を半分にすると直径は倍になった。写真の薄いレンズの式より約 5% 小さい（実験214）。
光の道 / Sun Glitterひかりのみち
低い太陽や月の下の水面に、縦に伸びて見える光の帯。細かい波の 1 つ 1 つが太陽を映した点の集まり。Karma では、水の材質の Roughness をほぼ 0（実践「夕暮れの海」では 0.015）にし、足もとの点を細かくしてさざ波を作ると出る。
Far Clippingファークリッピング
カメラが写す一番遠い距離。cam の既定は 10000（m）で、それより遠い物は写らずに透明になる。半径 20 km の空の球で包む場面では、1,000,000 などに上げておく（実践「夕暮れの海」）。
Render Visibilityレンダービジビリティ
オブジェクトを、カメラ・影・映り込みなどのどれに写すかを決める、Geometry オブジェクトのつまみ（vm_rendervisibility）。実践「冬の朝の七里ヶ浜」では、空の球に「-shadow」を入れても、Karma で平行光の影は消えなかった（空の内側に円い光を置いて解決）。
円い光 / Disk Lightまるいひかり
hlight の Light Type を disk にした、円い面から出る光。遠くに見かけ 0.54° の大きさで置くと、太陽の代わりになり、水面のきらめきにも丸い太陽として映る。Normalize Light Intensity to Area を切ると、Intensity がそのまま面の明るさになる（実践「冬の朝の七里ヶ浜」では 150,000）。
usdinstancerpathユーエスディーインスタンサーパス
パックした形に付ける文字の属性。USD に渡すとき、この名前のポイントインスタンサーにまとめる目印になる。ただし /obj の Karma で草 3 万本を撮ると、付けても付けなくても時間は同じだった（86 秒と 89 秒）。Solaris の sopimport で Packed Primitives を Create Point Instancer にすると 6.7 秒で撮れた（実験222）。
Time Samples（モーションブラー）タイムサンプルズ
Karma がシャッターの開いている間に、物の位置や形を何回調べるか。オブジェクトの動きは Transform Time Samples、形の変化は Geometry Time Samples（どちらも既定 2）。2 回だと、その間をまっすぐ結ぶので、速く回る物のブレが弧ではなく直線になる。オブジェクトの回転は既定の Rotation Blur で弧になるが、SOP で回すと Geometry Time Samples を 8 にしてやっと弧になった（90° 回る場合。実験230）。
Diffuse Limitディフューズリミット
Karma が、光がざらざらした面（壁・床など）で跳ね返るのを何回まで追うか。既定 1。窓の光だけで照らす明るい部屋では、1 だと本来の明るさの 72%、4 で 91%、8 で 98% になった。時間は 1 → 4 で 2 倍（実験234）。

USD と Solaris

Solaris（LOP）で出てくる、USD の舞台の言葉。

USD ステージ / Stageユーエスディーステージ
USD の舞台全体。いくつものレイヤーを重ねた結果として見えている、1つのシーン。Solaris の箱は、このステージを少しずつ書き換えていく。関連: USD, レイヤー（USD）
プリム / Primプリム
USD のステージに置かれる1つ1つの要素。形・光・カメラ・材質・入れ物（Xform）など。/world/geo/box のようなパスで場所を表す。SOP のプリミティブとは別物。
レイヤー（USD） / Layerレイヤー
USD の編集を書き込んだ1枚の紙。何枚も重ねて1つのステージになる。上の紙の書き込みが、下の紙より強い。
オピニオン / Opinionオピニオン
あるレイヤーが、ある属性に対して書いた値。同じ属性に複数のオピニオンがあると、強い方が勝つ。
コンポジション / Compositionコンポジション
レイヤー・参照・バリアントなどを組み合わせて、最終的なステージを作る仕組み。強さの順番（LIVRPS）が決まっている。
LIVRPSリブアールピーエス
USD で、どの書き込みが勝つかの強さの順番。Local・Inherits・VariantSets・References・Payloads・Specializes の頭文字。左ほど強い。
参照（USD） / Referenceさんしょう
別の USD ファイルの中身を、コピーせずに指し示して読み込むこと。元のファイルを直すと、参照している所すべてに反映される。
ペイロード / Payloadペイロード
あとから読み込むことにできる参照。重い部品を、必要になるまで読み込まずに置いておける。
バリアント / Variantバリアント
1つの物の中に持たせた、切り替えられる別案。色違い・形違い・細かさ違いなどを1つにまとめる。
Kindカインド
プリムの役割の札。component（部品）・assembly（組み立て）・group などがあり、選択や整理の単位になる。
Purposeパーパス
プリムの用途の札。render（本番の描画）・proxy（軽い代わり）・guide（目印）など。ビューポートとレンダーで出し分けられる。
インスタンサブル / Instanceableインスタンサブル
同じ参照を持つプリムの中身を共有させる印。大量に置いても、メモリが増えにくい。
Hydraハイドラ
USD のステージを描くための共通の仕組み。ビューポートや Karma は、Hydra を通してステージを描く。
Render Settings / Product / Varレンダーセッティング
USD でレンダリングの設定を表す3つのプリム。Settings が全体（カメラ・解像度）、Product が書き出す画像1枚、Var がその中の AOV 1つ。
Cryptomatteクリプトマット
物や材質ごとに色分けされた ID の画像。合成のときに、あとから好きな物だけを切り抜ける。
ポイントインスタンサー / Point Instancerポイントインスタンサー
同じ形を、位置・向きの表だけで大量に並べる USD のプリム。箱 1 万個で 0.32 MB と、1 個ずつプリムにするより何倍も小さかった（実験189・190）。

ファイルの受け渡し

外へ出す、外から入れるときの形式の言葉。

Alembicアレンビック
形と動きを他のソフトへ渡すための形式。焼き付いた結果を運ぶので軽いが、材質や仕掛けは持っていかない。実験058で書き出しを比べた。関連: USD, FBX
USDユーエスディー · Universal Scene Description
シーン全体を層に分けて記述する形式。あとから上書きの層を重ねられるのが特徴。Houdini では /stage で扱う。関連: Solaris
FBXエフビーエックス
形・骨・動きをまとめて運べる形式。ゲームエンジンへ渡すときによく使う。関連: Alembic
OBJオービージェー
点と面と UV だけを持つ、古くて単純な形式。アニメーションは持てない。素の形をやり取りするには確実。関連: bgeo
連番 / Sequenceれんばん
1フレームごとに別のファイルとして書き出す並び。name.0001.bgeo のように番号が入る。$F4 で桁を揃える。関連: $F
パディング / Paddingパディング
番号の桁を0で埋めて揃えること。1 を 0001 と書くと、並べ替えたときに順番が崩れない。関連: 連番
16 bit 浮動小数 / Half Floatじゅうろくビットふどうしょうすう
ふつう（32 bit）の半分の大きさで小数を持つ形。桁が少ないぶん値が少しずれる。焚き火の Pyro を VDB・16 bit で書くと、ファイルは 32 bit の 55% になり、値のずれは最大 0.00025（値の最大 1 に対して）だった（実験204）。
速度のボリューム / velベル
Pyro や FLIP が、升ごとの空気や水の速さを持つボリューム。vel.x・vel.y・vel.z の 3 つに分かれて出てくる。描画では主にモーションブラーに使う。煙の無い所でも 0 でないので、焚き火のキャッシュでは容量の 9 割以上を占めた（実験204）。

Houdini そのものに関する語

ファイル形式やツール名など、操作の周辺で出てくる語。

パラメータ / Parameterパラメータ
ノードの設定値。高さ、回数、サイズなど。parm と略される。Houdiniではこの値に数式を入れて他のノードと連動させられる。
クック / Cookクック
ノードが実際に計算を行うこと。パラメータや入力が変わると、そのノードと下流が再クックされる。重いノードを触ると待たされるのはこれが走っているため。
表示フラグ / Display flagディスプレイ・フラグ
どのノードの結果を画面に表示するかの指定。ノードの端に付く点で示される。「途中のノードを見る」ができるのはこの仕組みのおかげ。
バイパス / Bypassバイパス
ノードを一時的に無効にして、入力をそのまま下流に流すこと。そのノードの効果を消して比較したいときに使う。
HDAエイチディーエー · Houdini Digital Asset
作ったネットワークを1つのノードとしてまとめ、部品として再利用できるようにしたもの。中身を隠して必要なパラメータだけ外に出せる。
.hip / .hipncヒップ / ヒップエヌシー
Houdiniのシーンファイル。.hip が通常版で、.hipnc は非商用（Apprentice）版が保存する形式。.hipnc は商用版で開けない。
hythonハイソン
Houdiniの機能を使えるPython。GUIを開かずにノードを組んだりレンダリングしたりできるため、自動化の中心になる。関連: HOM
HOMホム · Houdini Object Model
PythonからHoudiniを操作するためのAPI。`hou` という名前のモジュールとして提供される。関連: hython
Apprenticeアプレンティス
無料で使える非商用ライセンス。出力にウォーターマークが入り、解像度は1920x1080まで、保存は .hipnc のみという制限がある。学習用途としては十分。
ハッシュ / Hashハッシュ
どんな長さのデータからでも、決まった長さの短い文字列を作る計算。元が1文字でも違えば結果は別物になる。実験027では、上流のネットワークからSHA-1 のハッシュを取り、キャッシュが古くなっていないかの判定に使った。
.hipncヒップエヌシー
Apprentice 版で保存したシーンのファイル。商用版の .hip とは別の拡張子で、商用版では開けない決まりになっている。関連: Apprentice
bgeoビージオ
Houdini が形を保存する独自の形式。アトリビュートもグループもそのまま残る。.bgeo.sc は圧縮されたもの。関連: ディスクキャッシュ
$HIPドルヒップ
いま開いているシーンのファイルがある場所を指す。ファイルの場所をこれで書くと、フォルダごと移しても壊れない。関連: 式
$Fドルエフ
いまのフレーム番号。$F4 と書くと 0001 のように4桁に揃う。連番のファイル名に使う。関連: 式, 連番
Solarisソラリス
USD でシーンを組み立てるための仕組み。/stage の中で動く。ライトや材質の割り当てをここでまとめる。関連: /stage, USD
Karma XPUカルマエックスピーユー
Karma のうち、GPU も使って速く描く方式。使える機能に制限があるため、CPU 版と結果が違うことがある。関連: Karma
MPMエムピーエム · Material Point Method
粒と升目を行き来させて、砂・雪・泥のような材質を解くやり方。固体と液体の中間のものを扱える。実験061〜076で測った。
つまみの式 / Parameter Expressionつまみのしき
つまみに値ではなく式（$F や ch() や @N など）が入っている状態。SOP では488個のつまみに最初から式が入っていた（実験134）。
deleteAllKeyframes()デリートオールキーフレームズ
Python でつまみの式やキーを全部消す命令。式が入ったつまみは、これで消してから set しないと値が変わらない（実験133・134）。
$FSTART / $FENDエフスタート
シーンの最初と最後のフレーム番号。キャッシュや読み込みの範囲に、最初から式として入っていることが多い。
intrinsic（内在属性）イントリンシック
形が最初から持っている読み取り用の値（pointcount・primitivecount など）。点を1つずつ数えるより速い。
振り返り点検（Audit）ふりかえりてんけん
このサイトで30件ごとに行う見直し。台本を全部流し直し、記録の数字と1つずつ比べる。150 では 122〜149 の28本がすべて一致した。
埋め込み HDA / Embeddedうめこみエイチディーエー
HDA（自作ノード）の定義を、別の .hda ファイルではなく hip の中にしまうこと。hip 1つを渡すだけで相手も使える。台本では createDigitalAsset(save_as_embedded=True)（実践「レンガ塀を HDA にする」）。
PDG / TOPsピーディージー / トップス
「番号や値を変えながら、同じ処理を何回も回し、結果をファイルに書き出す」仕組み。topnet の中に TOP ノード（wedge・ropgeometry など）を並べて組む。5つの石を1回の実行で書き出した（実践「PDG で形違いを一度に書き出す」）。
@wedgeindexアットウェッジインデックス
wedge が作った作業ごとに付く番号（0, 1, 2, …）。SOP のつまみの式やファイル名に `@wedgeindex` と書くと、作業ごとに違う値になる。PDG の外で見ると 0。
revertToDefaults()リバートトゥデフォルツ
Python（hou）で、つまみを既定値に戻す関数。戻る先は「つまみの既定値」で、ノードを作った直後の値とは限らない。pyrosolver の Use Control Field は、作った直後は「入り」なのに、revertToDefaults では「切り」に戻った（実験220）。作った直後の値に戻したいときは、その値を直接 set する。
