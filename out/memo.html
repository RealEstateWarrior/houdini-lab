あなたにお願いすること

あなた待ち
  • Claude 版を組織内限定にしてよいか返事待ち

    512の壁を外すには画像をアセット置き場へ移すしかなく、それを宣言したページは公開リンクで配れなくなる（組織内限定）。公開は GitHub 版が担うので実害は無いはずですが、共有の仕方が変わるので勝手には切り替えません。

  • Unreal Engine を入れる未インストール

    Epic のランチャーはありますが、エンジン本体が入っていません。要望ページの「Unreal Engine へ持っていく」もこれ待ちです。

  • Claude 版で「AI に聞く」が動くか確かめる未確認

    検索窓を開いて質問し、答えと「根拠にした記録」が出れば成功。出ない場合は表示されたメッセージを教えてください。

  • Unreal Engine は入っている？未確認

    Epic のランチャーはありますが、エンジン本体が入っていません。要望ページの「Unreal Engine へ持っていく」もこれ待ちです。

  • Cloudflare のアカウントと Gemini の鍵案B着手前

    案Bを選んだので、中継を1つ立てます。Workers の無料枠と Gemini の API キー取得はあなたの作業（鍵は私に見せず、Workers の Secret に入れてください）。私は中継のコードとサイト側を書きます。

  • Houdini 22 のライセンス動かせない

    22.0.368 は入っていますが、hython を起動すると「No licenses could be found」で止まります。21 のライセンスでは 22 は動きません。22 で測るならライセンスが必要です。

私の宿題

私がやる
  • 実践ページも JSON から組み立てる未着手

    実験記事（make_entry.py）と同じ形にして、HTML を手で書かない。ノードと用語は node_dump.py / nodes_merge.py の型ができた。

  • 画像をアセット置き場へ移す250実践の前提

    512の壁。概要ページは画像タグ577個・スマホで8517px。assets を宣言して上げ、URL を img に使う。宣言すると組織内限定になるが、公開は GitHub 版が担うので可。枠の総量はまだ確かめていない。

  • 一覧を索引表にする提案済み

    行の高さ44pxの表＋絞り込みを既定にし、大きな図版は数本だけ残す。実践250本では今の並べ方では開けない。

  • 実践ページも JSON から組み立てる未着手

    実験記事の make_entry.py と同じ形にして、HTML を手で書かない。掃き出し（sweep）ハーネスも作る。

  • Gemini 中継（案B）を書く鍵待ち

    Cloudflare Workers のコードと、GitHub版から呼ぶ側。質問ごとに添える記録を10件→4件に減らしてトークンを削る。

  • 要望フォームの送り先を自前にするか決める様子見

    いまは GitHub の投稿画面を開く形。送る人に GitHub のアカウントが要る。案Bの中継（Cloudflare Workers）を立てるなら、そこへ直接送る形にできる。

気になっていること（未解決）

未解決
  • 液体は、なぜ摩擦 1.5 以上だと暴れないのか

    実験073。摩擦 0〜1.5 の間だけ数粒が飛ぶ。止まるまでの時間と関係がありそうだが、確かめていない。

  • MPM の摩擦は、どこまで細かくすれば式に届くのか

    実験075。粒の間隔 0.04 で実効の摩擦 0.79。1.0 に届くのか、頭打ちなのかは未確認。

  • 旗の「抵抗 × 風速²」が1組だけ合わない

    実験081。(風速8・抵抗2.5) だけ 9度ずれた。抵抗が小さいときに外れるのかは未確認。

  • Claude 版のファイル数が上限に近い

    1つの版に置けるのは 512 まで。いまは 501。手順が増えたら、画像の置き方（アセット置き場など）を見直す。

  • Catmull-Clark の極限体積は計算で出せるか

    実験099で、立方体を割り続けると体積が元の約32.76%に落ち着くと分かった（1段ごとの減りが約1/4なので外挿）。理論値があるなら突き合わせたい。
